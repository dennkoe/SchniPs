Schnitzeljagd
Bislang wird Schnitzeljagd über QR Codes abgearbeitet. Der Code führt auf eine externe Lernplattform, welches ein Minispiel beinhaltet. Wird das Minispiel korrekt beendet, gibt's den Auftrag zum nächsten Standort zu gelangen und alles beginnt von vorn. 
Leider gehen mit der Zeit die ausgehängten QR Codes verloren. Diese Minianwendung befreit von den QR Codes. Die Anwesenheit am genannten Ort reicht nun aus, dass in der Webanwendung der Link zur nächsten Aufgabe erscheint. So kann künftig ausd as physische Aufhängen komplett verzichtet werden.
